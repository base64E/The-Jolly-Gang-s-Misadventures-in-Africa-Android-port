## 🇬🇧 English

### About the Project
This is an unofficial Android port of the classic point-and-click adventure game **"The Jolly Gang's Misadventures in Africa"** (Масяня в полной Африке), originally developed by Alawar Entertainment. 

### Features
* Optimized touch controls for Android devices.
* Smooth gameplay experience on modern smartphones and tablets.
* Faithful adaptation of the original PC version.

### Installation
1. Download the latest APK file from the [Releases](../../releases) section.

### Disclaimer
This port is created for educational and preservation purposes. All rights to the original game, characters, and assets belong to their respective copyright holders (Alawar / Oleg Kuvaev).
